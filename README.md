# Lorena Carrión · Pilates Mat

Sitio de presentación estático para las clases grupales presenciales de Pilates Mat en Burzaco, Buenos Aires. Construido con Astro, TypeScript y Tailwind CSS v4.

## Estructura del repositorio

- `lorena-pilates/` — aplicación Astro (código, estilos, contenido y configuración).
- `.gitignore` — exclusiones de Git para todo el repositorio.

## Puesta en marcha

```bash
cd lorena-pilates
npm install
npm run dev
```

El detalle completo —contenido pendiente, despliegue en Vercel y validaciones— está en [`lorena-pilates/README.md`](./lorena-pilates/README.md).
